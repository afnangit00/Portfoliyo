You are a world-class creative director, premium UI/UX designer, motion designer, and senior frontend engineer.

I am building my own unique website design identity called **AFNAN PREMIUM DIGITAL**.

The goal is NOT to create a generic template.

The goal is to create a recognizable visual identity that feels like it belongs to the same premium design studio, even when the business category changes.

---

# CORE DESIGN IDENTITY

Create a premium, cinematic, editorial-style website with:

* Luxury visual language
* Minimal but powerful layouts
* Large typography
* Strong whitespace
* High-quality photography
* Smooth cinematic transitions
* Elegant micro-interactions
* Premium hover effects
* Scroll-based animations
* Subtle parallax
* Editorial composition
* Strong visual hierarchy
* Sophisticated typography
* Modern asymmetric layouts
* Dark + off-white visual system
* High-end brand feeling
* Mobile-first responsive design

The website should feel like:

**Luxury brand + modern editorial magazine + high-end creative agency + premium product experience.**

Avoid the feeling of:

* Cheap template
* Generic SaaS
* Basic business website
* Over-designed dashboard
* Typical WordPress website
* Generic AI-generated landing page
* Excessive gradients
* Excessive glassmorphism
* Excessive rounded cards
* Random animations

The design must feel intentional, expensive and highly curated.

---

# SIGNATURE VISUAL LANGUAGE

Use this design DNA consistently across every project.

### Typography

Use a strong modern sans-serif for headings.

Headings should be:

* Large
* Bold
* Tight letter spacing
* Editorial
* Confident

Use an elegant serif/italic style selectively for emphasis.

Example:

"Built for"
"people who"
**"choose different."**

Do not overuse serif typography.

---

# COLOR SYSTEM

Primary background:

Warm off-white / ivory

Secondary:

Near-black / charcoal

Text:

Deep black

Muted text:

Warm gray

Accent:

Use ONLY one subtle accent color when appropriate for the business brand.

Never create rainbow-colored UI.

The overall design should remain sophisticated.

---

# LAYOUT SYSTEM

Do NOT make every section look like a standard centered card grid.

Use:

* Full-screen hero sections
* Large editorial typography
* Asymmetric grids
* Large image compositions
* Split layouts
* Horizontal scrolling sections
* Full-width visual sections
* Overlapping elements
* Numbered sections
* Thin borders
* Small uppercase labels
* Large whitespace

Use sections that feel visually connected.

The entire page should feel like one continuous experience rather than separate blocks.

---

# ANIMATION SYSTEM

Animation is an important part of the AFNAN identity.

Use Framer Motion or an equivalent modern animation library.

Animations should be:

* Smooth
* Cinematic
* Fast enough to feel responsive
* Subtle
* Purposeful

Use:

1. Hero text stagger reveal
2. Image reveal animation
3. Scroll reveal
4. Image scale on hover
5. Text movement on hover
6. Button micro-interaction
7. Navigation transition
8. Section entrance animation
9. Subtle parallax
10. Horizontal scrolling where appropriate
11. Page transition where useful

Do NOT animate everything.

Animation should communicate quality, not distract the user.

---

The hero must immediately communicate:

1. What the business sells
2. Why it is different
3. A strong visual identity
4. A clear CTA

Use cinematic photography.

Hero structure can include:

MAIN MASSIVE HEADLINE

Primary CTA

Secondary CTA

Large visual/product image

Small supporting statistics or information

The hero should feel like a premium campaign.

---

# IMAGE DIRECTION

Photography is extremely important.

Use large, high-quality images.

Images should feel:

* Professional
* Cinematic
* Editorial
* Premium
* Realistic
* Brand-focused

Do not use random stock-image layouts.

When possible, use full-bleed photography.

Images should become part of the layout itself.

Primary CTA

Use a premium animated menu.
